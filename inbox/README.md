# inbox

Once a year, add the new year's figures to `housing-inputs.xlsx` and upload it here, **replacing the old file with the same name**.
Uploading starts the "Update housing data" action, which rebuilds `data/housing-data.json`.

| Sheet | What goes in it | Where it comes from |
|---|---|---|
| House prices | Median house price for August, by region | REINZ's August release (mid-September) |
| Household income | Median weekly household income, year ended June, by region | Stats NZ's Household Labour Force Survey, via Figure.NZ |

Interest rates are taken from the nz-mortgage-rates project automatically.
